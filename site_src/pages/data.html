The data behind the model

1,137 labelled brain MRI slices in four classes. What is in them, how we split them, and what they cannot tell us.

Where the images come from

The images come from the Multi-Class Brain Tumor MRI Dataset published on Mendeley Data by Jamil and Khan (2025), under a CC BY 4.0 licence (doi:10.17632/82mtzd8x72.2). Each file is a single 2D axial slice, resized to 224 x 224 pixels, labelled with one of four classes.

The classes are close to balanced, so plain accuracy is a fair headline number. That would not hold for real screening, where healthy scans vastly outnumber tumors.

The 80/20 split is stratified, so each class appears in the same proportion in both sets. We checked the folders for exact duplicates between training and testing and found none, and only one near-duplicate pair.

Preparation and augmentation

  • Resizing and scaling. Images are resized to the model's input size and pixel values are scaled before they reach the network.
  • Augmentation. During training only, each image is randomly flipped left to right, rotated by up to about 15 degrees, and varied in brightness and contrast. This teaches the model that a tumor does not change class because the scan is slightly tilted or darker.
  • No augmentation at test time. The test images are fed in untouched so the score reflects real performance.

Limits of this data

  • No patient information. Files are numbered images, so we cannot tell which slices came from the same person. That makes the split-by-patient evaluation we want impossible, and probably inflates validation scores. Details.
  • One source. Scanner type, field strength and hospital protocol all affect how an MRI looks. A model trained on one source often does worse on another.
  • Slices, not scans. Real diagnosis looks through a whole 3D volume across several sequences.
  • Healthy images may differ in style. If the healthy slices were collected differently from the tumor slices, a model could pick up on that difference instead of on anatomy.
  • Four labels only. Other tumor types, strokes, infections and post-surgical changes are absent.
