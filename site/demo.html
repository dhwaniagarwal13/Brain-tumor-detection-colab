Try the classifier

Drop a brain MRI slice and see the model's probability for each of the four categories.

This hosted page cannot run the model

The classifier is a TensorFlow model that runs on a local server. To get live predictions, start webapp/run.bat from the project folder and open the address it prints. Your image then goes only to your own computer.

The prediction will appear here.

Before you read a result

  • Use a single axial brain slice. The model was trained on 2D slices of this kind. Whole scans, other body parts or photos of screens give meaningless output.
  • Confidence is not correctness. A model can be 95% sure and wrong. See how confidence is computed.
  • Expect mistakes. Meningioma is the hardest class, and the model was only tested on one dataset. See the results.
  • It is not a diagnosis. Only a clinician with the full scan and your history can say what a finding means.

NeuroScan

A student research project on classifying brain MRI slices. It is not a medical device and cannot diagnose, treat or rule out any condition. Anyone worried about symptoms or a scan should talk to a doctor.
